# WordPress теми и добавки

Урокът **„WordPress теми и добавки“** запознава учениците с предназначението на темите и добавките в WordPress, избора и активирането на подходяща тема, добавянето на нова функционалност и прилагането на добри практики при работа с тях.

## Съдържание на темата „WordPress теми и добавки“

- **WordPress теми**
  - **Предназначение** и **избор** на **подходяща тема**
- **WordPress добавки**
    - **Инсталиране** и **управление** на добавка**
- **Добри практики**
- **Пример:** Промяна на външния вид и добавяне на функционалност на WordPress сайт

## WordPress теми и добавки – упражнение

- Задача за промяна на **външния вид** и добавяне на **функционалност** на WordPress сайт
