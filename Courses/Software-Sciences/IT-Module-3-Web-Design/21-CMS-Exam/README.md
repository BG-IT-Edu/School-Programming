# Контролна работа: CMS

Тази контролна работа в два варианта е насочена към проверка и затвърждаване на знанията за **CMS** и **WordPress**, като включва теоретични въпроси с избираем отговор и практическа задача за създаване, организиране и публикуване на съдържание, както и за промяна на външния вид на WordPress сайт.

## Методически указания
- Изпитният вариант, който сме споделили, е **само примерен**.
