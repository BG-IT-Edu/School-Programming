 # Повишаване на сигурността в уеб

Урокът **„Повишаване на сигурността в уеб“** запознава учениците с основните рискове при използване на CMS, методите за защита на CMS сайт и значението на редовното създаване на резервни копия.

## Съдържание на темата „Повишаване на сигурността в уеб“

- **Рискове и методи на защита**
  - **Рискове** при **използване** на **CMS**
  - **Методи** за **защита** на **CMS сайт**
- **Резервни копия**
  - **Методи** за **резервно копие** в **WordPress**
  - **Правила** за **съхранение** на **копия**
- **Пример:** Резервно копие на WordPress сайт

## Повишаване на сигурността в уеб – проверка на знанията

- Въпроси с избираем отговор
- Практическа задача за създаване на **резервно копие** на WordPress сайт
